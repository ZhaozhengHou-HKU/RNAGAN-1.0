# RNAGAN-1.0
Author: Zhaozheng Hou

Project supported by Hong Kong Health and Medical Research Fund (11221746). Multipurpose Generative Adversarial Network for processing single cell / bulk RNA sequencing data.

Hou, Z., Lee, V. H., Kwong, D. L., Guan, X., Liu, Z., & Dai, W. (2026). RNAGAN: Train One and Get Four, Multipurpose Human RNA-Seq Analysis Tool with Enhanced Interpretability and Small Data Size Capability. https://doi.org/https://doi.org/10.64898/2026.03.17.712527

## Requirements
RNAGAN was developed and tested using **MATLAB R2025b or later** with the Deep Learning Toolbox.

Earlier MATLAB releases may not support all network components and export functions used in this project.

## Model Export
RNAGAN models can be exported to **TensorFlow-compatible formats** using MATLAB's model export functionality.

This allows users to:

- Deploy trained RNAGAN models outside MATLAB
- Integrate RNAGAN into TensorFlow-based workflows
- Incorporate RNAGAN modules into larger AI systems and multi-agent pipelines

Please refer to the MATLAB documentation for details regarding supported export options and TensorFlow compatibility.
